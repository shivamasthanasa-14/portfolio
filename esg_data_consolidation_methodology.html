The Starting Point

What the data actually looks like before this process runs

Twenty sites, five or more distinct data formats, converging on one manual bottleneck with no consistent audit trail on the way out. This is the actual starting condition the methodology below is built to fix, not a hypothetical worst case.

The Process

Seven stages, click through in order

Where Stage 4 Gets Hardest

Scope 3, Categories 1 and 4. Not "Scope 3" in general.

Purchased goods and services, plus upstream transportation. Both depend on suppliers self-reporting at inconsistent maturity, often several tiers removed from direct visibility. The workable fix is tiered: primary data from the highest-impact suppliers, spend-based estimation for the rest.

Run well, this stops being an annual scramble. Ownership, templates, and validation logic already exist before the next cycle opens, and the dataset becomes usable for more than compliance: benchmarking sites against each other, catching drift before it becomes a target miss, answering a customer's due diligence questionnaire without starting from zero.
